3. SCRIPT DESCRIPTIONS

3.1 cell1_clean_data.py

Purpose:
This script loads the raw Excel dataset, cleans the hydropower operation data,
standardizes column names, rebuilds the date-time structure, handles missing
values and abnormal values, resamples the data into hourly records, and creates
the planned outage input template.

Main outputs:
- cleaned_hourly_data.xlsx
- cleaned_hourly_data.parquet
- cell1_metadata.json
- Planned_Outages_Input.xlsx

Major processes:
- Raw Excel loading
- Three-row header flattening
- Column name standardization
- Date and time reconstruction
- Numeric conversion
- Missing value interpolation
- Short zero-run correction
- Spike smoothing
- KNN imputation
- Hourly resampling
- Plant-level generation recalculation
- Planned outage template generation


3.2 cell2_rbfnn.py

Purpose:
This script trains and evaluates the main Radial Basis Function Neural Network
(RBFNN) forecasting models for the Agus cascade plants. It uses a residual
forecasting design, where the model predicts generation change relative to the
current generation.

Main outputs:
- Trained RBFNN models
- RBFNN validation metrics
- RBFNN testing metrics
- RBFNN testing predictions
- Day-ahead 24-hour RBFNN forecast
- Training and validation metadata

Major processes:
- Feature engineering
- Chronological train-validation-test split
- Standard scaling
- KMeans initialization of RBF centers
- RBFNN model training
- Validation-based model selection
- Operational MAPE calculation
- MAE, RMSE, and R2 calculation
- Day-ahead forecasting using planned outage input


3.3 cell3_benchmark.py

Purpose:
This script trains and evaluates benchmark forecasting models for comparison
against the RBFNN model. The benchmark models are Random Forest and XGBoost.

Main outputs:
- Random Forest trained model and forecasts
- XGBoost trained model and forecasts
- Benchmark validation and testing metrics
- Benchmark testing predictions
- Benchmark day-ahead forecast files

Major processes:
- Benchmark feature engineering
- Chronological train-validation-test split
- Random Forest training and testing
- XGBoost training and testing
- Operational MAPE calculation
- MAE, RMSE, and R2 calculation
- Comparison-ready forecast output generation


3.4 cell4_generate_thesis_and_metrics.py

Purpose:
This script generates thesis-ready figures and organizes selected metadata files
for use in the results, discussion, and appendix sections.

Main outputs:
- Cleaned generation profile figures
- RBFNN actual-versus-forecast figures
- Error analysis figures
- Benchmark comparison figures
- Day-ahead forecast figures
- Organized model metric files

Major processes:
- Reading RBFNN and benchmark metrics
- Reading testing prediction files
- Generating actual-versus-forecast plots
- Generating MAPE and RMSE comparison plots
- Generating residual and scatter plots
- Exporting thesis-ready figures


3.5 streamlit_app.py

Purpose:
This script provides the graphical dashboard interface for the forecasting
system. It allows users to view data status, manage planned outage input, run
forecasting scripts, and inspect forecast outputs through an interactive
interface.

Main features:
- Dashboard overview
- Data management section
- Planned outage planning section
- RBFNN forecasting section
- Forecast visualization
- System information section

Main outputs shown in the dashboard:
- Cleaned data status
- Planned outage file
- RBFNN forecast output
- Plant-level forecast graphs
- Total cascade forecast graph
- Thesis figures and system metadata
