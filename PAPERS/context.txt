SLIDE 3: Chapter 1: Background of the Study

- The Agus-Pulangi complex is a major Mindanao hydropower resource.

- Generation is hydraulically coupled: upstream releases affect downstream inflow, head, and output.

SLIDE 11: Data Collection and Processing
What to put on the slide:
- Historical operational and environmental data were organized into hourly records.
- Data cleaning handled inconsistent headers, date-time alignment, numeric conversion, missing values, near-zero values, short zero runs, and spikes.
- Plant-level generation was recalculated from cleaned unit-level generation values.
- Unit outage states were converted into binary availability indicators.

SLIDE 12: Feature Engineering and Dataset Split
What to put on the slide:
- Input features include temporal indicators, lagged generation values, rolling statistics, generation differences, hydrologic variables, gate/elevation variables, and unit availability.
- Cascade-aware upstream generation features were included based on plant order.
- The final cleaned dataset contains 13,128 hourly rows and 55 columns.
- Chronological split: 70% training, 15% validation, and 15% testing.
- Testing period represents unseen data from April 11, 2025 to June 30, 2025.
Suggested visual: none required; use clean academic layout.
Presenter cue: Stress that chronological splitting prevents future data leakage.

SLIDE 13: Feature Engineering Inputs
What to put on the slide:
- Temporal features help the model learn hourly, weekly, monthly, weekend, and target-hour patterns.
- Lag features use previous generation values, such as 1 hour, 24 hours, and 168 hours before the forecast.
- Rolling features summarize recent behavior using moving mean, standard deviation, minimum, and maximum values.
- Outage features show unit availability and number of running units, which limit possible generation.
- Hydrologic features represent water-related conditions such as rainfall, outflow, elevation, gate, and spillway variables.
- Upstream cascade features help downstream plants account for upstream generation and water-release effects.
Suggested visual: none required; use clean academic layout.
Presenter cue: Explain that these features convert cleaned data into model-ready inputs for the RBFNN.

SLIDE 14: RBFNN Model Development
What to put on the slide:
- One RBFNN model was developed for each Agus plant.
- The model uses radial basis functions to represent nonlinear operating regimes.
- A residual or delta formulation predicts generation changes relative to current output.
- This helps keep short-term forecasts anchored to recent operating conditions.
- Model training used normalized variables and Mean Squared Error as the optimization objective.
- Tuned settings included the number of RBF centers, learning rate, and shrinkage value.
- RBF spreads were represented by trainable gamma values, initialized at 1.0 and learned during training.
Suggested visual: none required; use clean academic layout.
Presenter cue: Explain that centers and learning rate were selected through validation, while spreads/gamma were optimized as trainable model parameters.

SLIDE 15: Benchmark Models and Evaluation Metrics
What to put on the slide:
- Benchmark models: Random Forest and XGBoost.
- Metrics used: MAPE, MAE, RMSE, and R2.
- MAPE measures relative percentage error and is easy to interpret for forecasting accuracy.
- MAE and RMSE measure error magnitude in MW, with RMSE penalizing larger errors more strongly.
- R2 measures how well the model explains generation variability.
