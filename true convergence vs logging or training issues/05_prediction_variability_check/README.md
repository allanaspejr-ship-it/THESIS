# 05 Prediction Variability Check

Place prediction distribution checks here.

## What to Include

- Descriptive statistics of predictions: mean, standard deviation, minimum, maximum.
- Histogram of predicted values.
- Comparison of actual and predicted standard deviation.

## What This Verifies

This checks whether the RBFNN is producing varied forecasts instead of a constant output.

## Good Sign

Predictions show meaningful variation and are not concentrated around a single value.

## Warning Sign

Predicted values have near-zero standard deviation or appear almost constant across all samples.
