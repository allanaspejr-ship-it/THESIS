# 06 RBF Centers and Spreads

Place RBF center and spread/width inspection outputs here.

## What to Include

- Number of RBF centers.
- Center values or center summary statistics.
- Spread, sigma, width, or gamma values.
- Notes on how centers were selected, such as k-means or random sampling.

## What This Verifies

This checks whether the RBF hidden layer was constructed correctly.

## Good Sign

Centers are valid, spreads are positive, and values are consistent with the scaled input data.

## Warning Sign

Centers are missing, duplicated excessively, outside the expected data range, or spreads are zero/invalid.
