# 02 Forecasting Metrics

Place metric tables or CSV files here.

## What to Include

- RMSE
- MAE
- MAPE
- NSE
- R2
- Training and validation metrics, if available

## What This Verifies

This checks whether the flat loss curve corresponds to acceptable forecasting performance.

## Good Sign

The RBFNN has reasonable error values and performs better than simple baseline models.

## Warning Sign

Loss is flat but RMSE, MAE, MAPE, NSE, or R2 indicate poor predictive performance.
