HYDROPOWER FORECASTING SYSTEM USER GUIDE

This guide is for Windows users who will run the hydropower forecasting system using the graphical dashboard or VS Code.

You do not need programming experience.

Follow the steps slowly.
Click what the guide says.
Type commands exactly when commands are needed.
Press Enter after each command.

====================================================
2. PROJECT OVERVIEW
====================================================

This system forecasts next-day hydropower generation for the Agus hydropower plants.

The main AI model is:

RBFNN

RBFNN means Radial Basis Function Neural Network.

The system can:

1. Clean raw Excel data.
2. Train the RBFNN AI model.
3. Forecast day-ahead hydropower generation.
4. Edit planned unit outages.
5. Generate forecast charts and result files.
6. Compare the RBFNN with benchmark models through scripts.
7. Open a graphical dashboard for easier daily use.

The dashboard is the recommended way to use the system for daily forecasting.

The dashboard uses the final RBFNN workflow only.

Benchmark models are still available in the scripts for thesis comparison, but they are not part of the main dashboard workflow.


Important folders and files:

data
- Put the raw Excel data file here.

scripts
- Contains Python files that run cleaning, forecasting, benchmarks, and thesis figures.

models
- Stores trained RBFNN model files.

outputs
- Stores cleaned data, planned outage files, and forecast results.

metadata
- Stores metrics and model information.

benchmark
- Stores Random Forest and XGBoost benchmark results.

thesis_figures
- Stores graphs and figures for the thesis.

streamlit_app.py
- Main graphical dashboard file.

RUN_DASHBOARD.bat
- Windows launcher for the dashboard.

7. INSTALL REQUIRED LIBRARIES
====================================================

Libraries are extra Python tools needed by the system.

1. Open the terminal.
2. Type:

python -m pip install --upgrade pip setuptools wheel

3. Press Enter.
4. Wait until it finishes.

If VS Code opened the Thesis Forecasting folder, type:

python -m pip install -r ../requirements.txt

Press Enter.

If VS Code opened the main HYDRO_FORECASTING folder, type:

python -m pip install -r requirements.txt

Press Enter.

If the requirements command says the file is missing, type:

python -m pip install numpy pandas openpyxl pyarrow joblib scikit-learn tensorflow xgboost matplotlib plotly streamlit watchdog jupyter ipykernel

Press Enter.

Important:

The dashboard needs Streamlit.

If the dashboard does not open, install Streamlit:

python -m pip install streamlit

- Retrains the RBFNN model.
- Use only when needed.

Important:

For normal daily use, click Forecast Day-Ahead.

Do not click Retrain RBFNN Model unless new data was added, model files were deleted, or accuracy needs improvement.

Do not run data cleaning again unless the raw Excel data changed.

====================================================
12. RUN THE SYSTEM BY TERMINAL (FULL PROCESS)
====================================================

Use this full terminal process when running the system for the first time or when preparing thesis outputs.

Make sure VS Code opened:

Thesis Forecasting


STEP 1: Clean Data

Type:

python scripts/cell1_clean_data.py

Press Enter.

This creates:

cleaned_hourly_data.xlsx
cleaned_hourly_data.parquet
Planned_Outages_Input.xlsx


STEP 2: Train RBFNN AI Model

Type:

python scripts/cell2_rbfnn.py --train

Press Enter.

This trains the RBFNN model, saves model files, creates metrics, and creates forecast outputs.

Training may take time.

Use this step when running the system for the first time, after adding a large amount of new historical data, or after model files were deleted.

Do not use --train for normal daily forecasting.


STEP 3: Run Benchmark Models

Type:

python scripts/cell3_benchmark.py --train

Press Enter.

This runs:

Random Forest
XGBoost

Use this step for thesis comparison.


STEP 4: Generate Thesis Figures and Metrics

Type:

python scripts/cell4_generate_thesis_and_metrics.py

Press Enter.

This creates graphs and organized results.


====================================================
13. FORECAST ONLY BY TERMINAL (NO RETRAINING)
====================================================

Use this for daily forecasting if you do not use the dashboard.

If models already exist, do not retrain.

Do not type --train for daily use.

To forecast only:

python scripts/cell2_rbfnn.py --forecast-only

You may also type:

python scripts/cell2_rbfnn.py

Both commands run fast forecast-only mode.

Forecast-only mode does:

1. Load saved cleaned data.
2. Load saved planned outage file.
3. Load saved RBFNN models and scalers.
4. Generate the 24-hour forecast.
5. Save only the RBFNN forecast Excel and CSV files.

Forecast-only mode does not:

retrain the RBFNN
run data cleaning
run benchmark models
regenerate thesis figures
recompute validation/testing metrics

Optional benchmark scripts should be used only for thesis comparison, not for daily forecasting:

python scripts/cell3_benchmark.py


====================================================
14. RETRAIN MODEL
====================================================

Only retrain when needed.

Retrain if:

new historical data was added and you want the model to learn from it
a large new dataset was added, such as several months or one year of records
model files were deleted
accuracy needs improvement

You do not need to retrain when only the outage plan changes.

You do not need to retrain for every daily forecast.

Dashboard retraining:

1. Open the dashboard.
2. If raw data changed, go to Data Management.
3. Click Run Data Cleaning.
4. Go to Planned Outage Planning.
5. Click Retrain RBFNN Model.

Terminal retraining:

python scripts/cell2_rbfnn.py --train

For daily use, use Forecast Day-Ahead or forecast-only instead.

====================================================
18. COMMON ERRORS AND FIXES
====================================================

Error:

python is not recognized

Meaning:

Windows cannot find Python.

Fix:

Reinstall Python.
During installation, check:

Add Python to PATH

Then restart VS Code.


Error:

Wrong Python version

Meaning:

The project should use 64-bit Python 3.11 on Windows.

Fix:

Install 64-bit Python 3.11.
Check Add Python to PATH.
Restart VS Code.


Error:

ModuleNotFoundError

Example:

No module named pandas

Meaning:

A required library is missing.

Fix:

python -m pip install --upgrade pip setuptools wheel

Then:

python -m pip install -r ../requirements.txt

If the requirements command fails:

python -m pip install numpy pandas openpyxl pyarrow joblib scikit-learn tensorflow xgboost matplotlib plotly streamlit watchdog jupyter ipykernel


Error:

streamlit is not recognized

Meaning:

Streamlit is missing or Windows cannot find it.

Fix:

python -m pip install streamlit

Then run:

python -m streamlit run streamlit_app.py


Error:

Dashboard does not open in browser

Meaning:

The dashboard server may be running, but the browser did not open automatically.

Fix:

Open your browser and go to:

http://localhost:8501


Error:

Port 8501 is already in use

Meaning:

Another Streamlit dashboard is already running.

Fix:

Close the old terminal window.

If it still happens, run:

python -m streamlit run streamlit_app.py --server.port 8502

Then open:

http://localhost:8502


Error:

Excel file is open

Meaning:

Python cannot edit the Excel file because Excel is using it.

Fix:

Save the Excel file.
Close Excel.
Run again.


Error:

Missing raw Excel file

Meaning:

The data file is not in the correct folder.

Fix:

Check that the file is here:

Thesis Forecasting/data/DATA(JAN2024-JUNE2025).xlsx


Error:

Missing cleaned data

Meaning:

The system needs cleaned data first.

Fix in dashboard:

Go to Data Management.
Click Run Data Cleaning.

Fix in terminal:

python scripts/cell1_clean_data.py


Error:

Missing model files

Meaning:

The model has not been trained yet, or model files were deleted.

Fix:

python scripts/cell2_rbfnn.py --train


Error:

Dashboard says forecast file is missing

Meaning:

The RBFNN forecast has not been generated yet.

Fix in dashboard:

Go to Planned Outage Planning.
Click Forecast Day-Ahead.

Fix in terminal:

python scripts/cell2_rbfnn.py --forecast-only
