PROJECT SETUP AND USER GUIDE
HYDRO_FORECASTING - AGUS CASCADE DAY-AHEAD FORECASTING

This guide explains how to install, run, and update the forecasting workflow from a fresh copy of the project.


1. REQUIRED SOFTWARE

Install these first:

1. Windows 10 or Windows 11.
2. 64-bit Python 3.11.
3. A code editor is optional. Visual Studio Code is recommended but not required.

When installing Python, check:

Add python.exe to PATH

After installing Python, open Command Prompt or PowerShell and check:

python --version

Expected result:

Python 3.11.x


2. DOWNLOAD OR COPY THE PROJECT

Put the project folder in a normal local folder, for example:

C:\Users\<YourName>\Desktop\HYDRO_FORECASTING

The folder should contain:

README.md
requirements.txt
Thesis Forecasting\

Inside Thesis Forecasting, the important items are:

streamlit_app.py
RUN_DASHBOARD.bat
data\
outputs\
models\
metadata\
scripts\


3. INSTALL PYTHON DEPENDENCIES

Open PowerShell in the project root folder.

Example:

cd "C:\Users\<YourName>\Desktop\HYDRO_FORECASTING"

Upgrade pip tools:

python -m pip install --upgrade pip setuptools wheel

Install the project dependencies:

python -m pip install -r requirements.txt

This installs the dashboard, data processing, machine learning, Excel, and plotting packages.


4. CHECK THE RAW DATA FILE

The raw Excel file must be here:

Thesis Forecasting\data\DATA(JAN2024-JUNE2025).xlsx

If the raw data changes, replace that Excel file with the updated source file using the same filename.


5. RUN THE DASHBOARD

The easiest method is:

1. Open the Thesis Forecasting folder.
2. Double-click RUN_DASHBOARD.bat.
3. Wait for Streamlit to start.
4. The dashboard should open in your browser.

If the browser does not open automatically, look in the command window for a local URL similar to:

http://localhost:8501

Open that URL in your browser.

Manual dashboard command from the project root:

python -m streamlit run "Thesis Forecasting\streamlit_app.py"


6. NORMAL DAILY FORECASTING WORKFLOW

Use this when the models are already trained and you only need a new forecast.

Step 1: Open the dashboard.

Thesis Forecasting\RUN_DASHBOARD.bat

Step 2: Review or update planned outages in the dashboard.

The outage workbook is stored at:

Thesis Forecasting\outputs\outages_planning\Planned_Outages_Input.xlsx

Step 3: Run the forecast from the dashboard if using the dashboard buttons.

Alternative command-line forecast:

python "Thesis Forecasting\scripts\cell2_rbfnn.py" --forecast-only

Step 4: Check the RBFNN forecast output:

Thesis Forecasting\outputs\rbfnn_forecast\Day_Ahead_24H_RBFNN_Forecast.xlsx
Thesis Forecasting\outputs\rbfnn_forecast\Day_Ahead_24H_RBFNN_Forecast.csv


7. FULL REBUILD WORKFLOW

Use this when setting up from raw data, replacing the raw Excel file, or rebuilding all outputs.

Run these commands from the project root:

Step 1: Clean the raw Excel file and create cleaned hourly data.

python "Thesis Forecasting\scripts\cell1_clean_data.py"

Outputs:

Thesis Forecasting\outputs\cleaned_data\cleaned_hourly_data.xlsx
Thesis Forecasting\outputs\cleaned_data\cleaned_hourly_data.parquet
Thesis Forecasting\outputs\outages_planning\Planned_Outages_Input.xlsx

Step 2: Generate the RBFNN forecast using saved models.

python "Thesis Forecasting\scripts\cell2_rbfnn.py" --forecast-only

Outputs:

Thesis Forecasting\outputs\rbfnn_forecast\Day_Ahead_24H_RBFNN_Forecast.xlsx
Thesis Forecasting\outputs\rbfnn_forecast\Day_Ahead_24H_RBFNN_Forecast.csv

Step 3: Generate benchmark forecasts using saved Random Forest and XGBoost models.

python "Thesis Forecasting\scripts\cell3_benchmark.py" --forecast-only

Outputs:

Thesis Forecasting\outputs\random_forest_forecast\Day_Ahead_24H_RANDOM_FOREST.xlsx
Thesis Forecasting\outputs\xgboost_forecast\Day_Ahead_24H_XGBOOST.xlsx

Step 4: Open the dashboard.

python -m streamlit run "Thesis Forecasting\streamlit_app.py"


8. RETRAINING WORKFLOW

Retraining is slower than forecast-only mode. Use retraining only when the study needs updated model artifacts or new evaluation results.

Retrain RBFNN models:

python "Thesis Forecasting\scripts\cell2_rbfnn.py" --train

Retrain benchmark models:

python "Thesis Forecasting\scripts\cell3_benchmark.py" --train

Retrain selected RBFNN plants only:

python "Thesis Forecasting\scripts\cell2_rbfnn.py" --train agus1 agus2

Retrain selected benchmark plants only:

python "Thesis Forecasting\scripts\cell3_benchmark.py" --train agus1 agus2

Valid plant keys:

agus1
agus2
agus4
agus5
agus6
agus7


9. OPTIONAL METRICS AND FIGURE GENERATION

Use this after forecasts or model metrics are updated:

python "Thesis Forecasting\scripts\cell4_generate_thesis_and_metrics.py"

This can regenerate thesis-style metrics and figure outputs under the Thesis Forecasting folder.


10. IMPORTANT FOLDERS

Keep these folders because the dashboard and workflow depend on them:

Thesis Forecasting\data
Thesis Forecasting\outputs
Thesis Forecasting\models
Thesis Forecasting\metadata
Thesis Forecasting\scripts

Main dashboard file:

Thesis Forecasting\streamlit_app.py

Dashboard launcher:

Thesis Forecasting\RUN_DASHBOARD.bat


11. COMMON PROBLEMS AND FIXES

Problem:
streamlit is not recognized or No module named streamlit

Fix:
Run dependency installation again:

python -m pip install -r requirements.txt


Problem:
File does not exist: scripts\streamlit_app.py

Fix:
Use the updated launcher:

Thesis Forecasting\RUN_DASHBOARD.bat

Or run:

python -m streamlit run "Thesis Forecasting\streamlit_app.py"


Problem:
Raw Excel file is missing.

Fix:
Make sure this file exists:

Thesis Forecasting\data\DATA(JAN2024-JUNE2025).xlsx


Problem:
Cleaned data is missing.

Fix:
Run:

python "Thesis Forecasting\scripts\cell1_clean_data.py"


Problem:
Saved model is missing.

Fix:
If saved model files were deleted, retrain:

python "Thesis Forecasting\scripts\cell2_rbfnn.py" --train
python "Thesis Forecasting\scripts\cell3_benchmark.py" --train


12. RECOMMENDED SIMPLE USE

For routine use:

1. Double-click Thesis Forecasting\RUN_DASHBOARD.bat.
2. Update planned outages if needed.
3. Run or refresh the forecast.
4. Use the output Excel file in Thesis Forecasting\outputs\rbfnn_forecast.

For a full rebuild:

1. Install dependencies.
2. Confirm the raw Excel file exists.
3. Run cell1_clean_data.py.
4. Run cell2_rbfnn.py --forecast-only.
5. Run cell3_benchmark.py --forecast-only if benchmark forecasts are needed.
6. Open the dashboard.
