HYDROPOWER FORECASTING SYSTEM USER GUIDE

This guide is for Windows users who will run the hydropower forecasting system using VS Code.

You do not need programming experience.

Follow the steps slowly.
Click what the guide says.
Type the commands exactly.
Press Enter after each command.

HYDROPOWER FORECASTING SYSTEM USER GUIDE


====================================================
2. PROJECT OVERVIEW
====================================================

This system forecasts next-day hydropower generation for the Agus plants.

This means the system uses past data to estimate how much power the Agus hydropower plants may generate tomorrow.

The system uses AI.

The main AI model is called:

RBFNN

RBFNN means Radial Basis Function Neural Network.

You do not need to understand the math to use the system.

The system can do these tasks:

1. Clean the raw data.
2. Train the AI model.
3. Forecast hydropower generation.
4. Generate graphs and results.
5. Compare the AI model with benchmark models.

Important folders:

data
- This is where you put the raw Excel data file.

scripts
- This contains the Python files that run the system.

models
- This stores trained AI model files.

outputs
- This stores cleaned data, outage files, and forecast results.

metadata
- This stores metrics and model information.

benchmark
- This stores Random Forest and XGBoost benchmark results.

thesis_figures
- This stores graphs and figures for the thesis.

3. INSTALL REQUIRED SOFTWARE
====================================================

A. Install Python

1. Open your web browser.
2. Go to:

https://www.python.org/downloads/

3. Click Download Python.
4. Wait for the installer to download.
5. Open the installer.
6. IMPORTANT: Check the box that says:

Add Python to PATH

7. Click Install Now.
8. Wait for the installation to finish.
9. Click Close.

To check if Python is installed:

1. Open VS Code later.
2. Open the terminal.
3. Type:

python --version

4. Press Enter.
5. If you see a Python version, Python is installed.


B. Install VS Code

1. Open your web browser.
2. Go to:

https://code.visualstudio.com/

3. Click Download for Windows.
4. Wait for the installer to download.
5. Open the installer.
6. Click Next.
7. Accept the agreement.
8. Click Next.
9. Click Install.
10. Wait for the installation to finish.
11. Open VS Code.


C. Install Excel

You need a program that can open Excel files.

Use one of these:

Microsoft Excel
LibreOffice Calc

If Microsoft Excel is already installed, you can use it.

====================================================
7. INSTALL REQUIRED LIBRARIES
====================================================

Libraries are extra tools that Python needs to run the forecasting system.

1. Make sure the terminal is open.
2. Click inside the terminal.
3. Type this:

python -m pip install --upgrade pip

4. Press Enter.
5. Wait until it finishes.

Then install the required libraries.

Type this:

python -m pip install numpy pandas matplotlib openpyxl scikit-learn tensorflow xgboost pyarrow joblib

Press Enter.

Wait until it finishes.

This may take several minutes.

If there is a requirements.txt file, you can use this command instead:

python -m pip install -r requirements.txt

Press Enter.

If the command says the file is missing, use the longer command above.

DATA(JAN2024-JUNE2025).xlsx

3. Copy the file.

Thesis Forecasting

Thesis Forecasting/data/

====================================================
9. RUN THE SYSTEM (FULL PROCESS)
====================================================

Use this full process when running the system for the first time.

Make sure VS Code has opened the folder:

Thesis Forecasting

Make sure the terminal is open.


STEP 1: Clean Data

1. Click inside the terminal.
2. Type this:

python scripts/cell1_clean_data.py

3. Press Enter.
4. Wait until it finishes.

This step creates:

cleaned data
outage template

Example outputs:

cleaned_hourly_data.xlsx
cleaned_hourly_data.parquet
Planned_Outages_Input.xlsx


STEP 2: Train AI Model

1. Click inside the terminal.
2. Type this:

python scripts/cell2_rbfnn.py --train

3. Press Enter.
4. Wait until it finishes.

This step will:

train the AI model
save model files
create metrics
create forecast outputs

This may take time.


STEP 3: Run Benchmark Models

1. Click inside the terminal.
2. Type this:

python scripts/cell3_benchmark.py --train

3. Press Enter.
4. Wait until it finishes.

This step runs comparison models.

The benchmark models are:

Random Forest
XGBoost


STEP 4: Generate Figures and Metrics

1. Click inside the terminal.
2. Type this:

python scripts/cell4_generate_thesis_and_metrics.py

3. Press Enter.
4. Wait until it finishes.

This step creates graphs and organized results.

====================================================
11. RETRAIN MODEL (WHEN NEEDED)
====================================================

Only retrain when needed.

Retrain only if:

new data was added
model files were deleted

To retrain:

1. Click inside the terminal.
2. Type this:

python scripts/cell2_rbfnn.py --train

3. Press Enter.
4. Wait until it finishes.

====================================================
12. EDIT PLANNED OUTAGE
====================================================

The planned outage file tells the system which units are ON or OFF.

First, run Step 1 from the full process if the outage file does not exist yet.

Open this file:

outputs/outages_planning/Planned_Outages_Input.xlsx

Steps:

1. Open the outputs folder.
2. Open the outages_planning folder.
3. Open Planned_Outages_Input.xlsx.
4. Edit the values.

Use these values:

1 = ON
0 = OFF

5. Save the Excel file.
6. Close Excel.
7. Go back to VS Code.
8. Open the terminal.
9. Run forecast again:

python scripts/cell2_rbfnn.py

10. Press Enter.

Important:

Always close Excel before running the script.

====================================================
15. COMMON ERRORS (AND FIX)
====================================================

Error:

python is not recognized

Meaning:

Windows cannot find Python.

Fix:

Reinstall Python.
During installation, check:

Add Python to PATH

Then restart VS Code.


Error:

ModuleNotFoundError

Example:

No module named pandas

Meaning:

A required library is missing.

Fix:

Open the terminal and type:

python -m pip install numpy pandas matplotlib openpyxl scikit-learn tensorflow xgboost pyarrow joblib

Press Enter.


Error:

Excel file is open

Meaning:

Python cannot edit the Excel file because Excel is using it.

Fix:

Save the Excel file.
Close Excel.
Run the command again.


Error:

Missing file

Meaning:

The file is not in the correct folder.

Fix:

Check that the data file is inside:

Thesis Forecasting/data/

Check that the file name is:

DATA(JAN2024-JUNE2025).xlsx


Error:

Missing cleaned data

Meaning:

The system needs cleaned data first.

Fix:

Run:

python scripts/cell1_clean_data.py


Error:

Missing model files

Meaning:

The model has not been trained yet, or files were deleted.

Fix:

Run:

python scripts/cell2_rbfnn.py --train
