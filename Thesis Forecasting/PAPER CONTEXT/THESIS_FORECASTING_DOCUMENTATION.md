# Thesis Forecasting Documentation

## Overview

`Thesis Forecasting` is the renamed and organized forecasting workflow that previously lived under `optimized_v2`. The scripts now resolve paths from the `Thesis Forecasting` folder itself, so the workflow can be run without an `optimized_v2` directory.

The workflow keeps these folders in place:

- `data/` for the source Excel dataset.
- `outputs/` for cleaned data, outage planning input, testing plots, and RBFNN forecasts.
- `models/` for trained RBFNN, Random Forest, and XGBoost models.
- `metadata/` for validation, testing, organized metrics, and comparisons.
- `benchmark/` for Random Forest and XGBoost day-ahead forecast outputs.
- `thesis_figures/` for Chapter 4 figures generated by Cell 4.
- `scripts/` for the executable Python cells.

## Script Order

Run scripts from the repository root or from inside `Thesis Forecasting`; each script uses `pathlib` and resolves its own folder paths.

```powershell
python "Thesis Forecasting/scripts/cell1_clean_data.py"
python "Thesis Forecasting/scripts/cell2_rbfnn.py"
python "Thesis Forecasting/scripts/cell3_benchmark.py"
python "Thesis Forecasting/scripts/cell4_generate_thesis_and_metrics.py"
```

Optional full testing split comparison plots:

```powershell
python "Thesis Forecasting/scripts/cell4_testing_plots.py"
```

## Cell Responsibilities

### Cell 1: Clean Data

`scripts/cell1_clean_data.py` reads:

- `data/DATA(JAN2024-JUNE2025).xlsx`

It writes:

- `outputs/cleaned_data/cleaned_hourly_data.parquet`
- `outputs/cleaned_data/cleaned_hourly_data.xlsx`
- `outputs/outages_planning/Planned_Outages_Input.xlsx`

### Cell 2: RBFNN Forecasting

`scripts/cell2_rbfnn.py` reads cleaned data and planned outages from `outputs/`.

It writes:

- RBFNN models under `models/rbfnn/`
- validation and testing metrics under `metadata/validation_metrics/`, `metadata/testing_metrics/`, and `metadata/overall_metrics/`
- RBFNN day-ahead forecast files under `outputs/rbfnn_forecast/`

### Cell 3: Benchmark Models

`scripts/cell3_benchmark.py` reads cleaned data and planned outages from `outputs/`.

It writes:

- Random Forest models under `models/random_forest/`
- XGBoost models under `models/xgboost/`
- benchmark metrics under `metadata/overall_metrics/`
- day-ahead forecast files under `benchmark/random_forest/` and `benchmark/xgboost/`

### Cell 4: Thesis Figures and Organized Metadata

`scripts/cell4_generate_thesis_and_metrics.py` reads the cleaned data, model testing predictions, model validation/testing summaries, and day-ahead forecast workbooks.

It writes:

- Chapter 4 thesis figures under `thesis_figures/`
- organized RBFNN metadata under `metadata/rbfnn/`
- organized Random Forest metadata under `metadata/random_forest/`
- organized XGBoost metadata under `metadata/xgboost/`
- overall comparison workbooks under `metadata/overall_comparison/`

Training-validation loss figures are generated only when usable RBFNN training history files exist. If no training history exists, the script prints warnings and skips those figures.

## Path Migration Notes

Cells 1, 2, 3, and 4 now use the renamed folder as their base:

```python
THESIS_DIR = Path(__file__).resolve().parents[1]
```

Cells 2 and 3 no longer use:

```python
PROJECT_DIR / "optimized_v2"
```

Legacy model fallback paths point to:

```text
archive/optimized_version/
```

## Git Notes

The folder rename should be tracked as a move from `optimized_v2/` to `Thesis Forecasting/` for the source files that were already tracked. Large generated model/data/output files should only be committed intentionally.
